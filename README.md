# LeetCode Practice

This repo is where I track my daily LeetCode problem-solving as part of my prep for Software Development Engineer (SDE) internships and continous learning.

## What this is

- A running log of problems I've solved, organized by problem number and name
- Each folder contains my solution and, where useful, a short note on my approach and time/space complexity
- Not meant to be a "perfect answers" archive — some solutions are brute-force first attempts before I optimize them

## Structure

```
LeetCode-Practice/
├── 0001-two-sum/
│   └── solution.py
├── 0002-add-two-numbers/
│   └── solution.py
└── ...
```

## Why I'm doing this

Consistent problem-solving practice is core to interview prep for SDE roles. This repo helps me:
- Build a daily coding habit
- Track progress across topics (arrays, hashmaps, trees, DP, etc.)
- Have a visible record of consistent effort for anyone reviewing my GitHub

## Tech

Solutions are primarily in Python, with some in JavaScript depending on the problem.
